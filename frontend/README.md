# LearnHub Web

React frontend for LearnHub (Vite + TypeScript + Tailwind CSS + shadcn/ui).

Run commands from the repository root:

```text
npm run dev:web      # dev server on http://localhost:5173 (proxies /api to the API on :4000)
npm run check        # typecheck + lint all workspaces, then Prettier check
```

Start the API too (`npm run dev:api`) so `/api` requests work in development.
